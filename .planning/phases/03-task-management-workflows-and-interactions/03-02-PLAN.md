# Phase 3: Plan 2 - Add & Edit Task Bottom Sheet Modal

## Objective
Implement the Figma Frame 3 task authoring bottom sheet modal (`TaskModal.tsx`) supporting both task creation and editing, complete with title input, dual start/end time pickers, formatted date picker, description textarea, priority selection chips, and form validation.

## Proposed File Changes
- `Frontend/src/components/tasks/TaskModal.tsx`:
  - Backdrop overlay with smooth fade-in animation and click-outside dismissal.
  - Header: "Add New Task" / "Edit Task" title with close `✕` icon.
  - "Task title" input field with character counter and mandatory field validation.
  - "Set Time": side-by-side start time and end time selectors with clock icons.
  - "Set Date": date selector with calendar icon and human-friendly date formatting ("Friday 14, January").
  - "Description": multiline textarea with "Add Description" placeholder.
  - "Priority": selectable chips for `Low`, `Medium`, and `High` priorities.
  - Full-width blue action button ("Create task" / "Save changes").
  - Form validation: enforces non-empty title, valid date, and time inputs before submission.

## Verification Steps
1. Build frontend bundle using `npm run build` with zero TypeScript errors.
2. Verify modal renders all fields matching Figma Frame 3.
3. Verify form validation catches empty title or invalid dates.
4. Verify pre-population of fields when in edit mode.
