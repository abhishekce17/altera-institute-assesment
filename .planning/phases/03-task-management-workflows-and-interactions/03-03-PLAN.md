# Phase 3: Plan 3 - Dedicated Search Screen (Frame 9), State Management & Interaction Assembly

## Objective
Implement the dedicated Search view matching Figma Frame 9, build a client-side state manager (`useTasks.ts`) with realistic sample data and live weekly metrics computation, and wire together all interactive flows (FAB modal trigger, task editing, swipe/trash deletion, search navigation).

## Proposed File Changes
- `Frontend/src/hooks/useTasks.ts`:
  - Centralized task state preloaded with realistic tasks from Figma mockups ("Finishing Wireframe", "Meeting with team", "Buy a cat food", "Finishing daily commission", "Doing Homework").
  - Dynamically calculates `WeeklyStats` (`completed`, `open`, `total`, `progressPercentage`).
  - Action dispatchers: `createTask`, `updateTask`, `toggleTaskStatus`, `deleteTask`.
- `Frontend/src/components/search/SearchScreen.tsx`:
  - Full-screen search view matching Figma Frame 9.
  - Top navigation with back arrow `←` button returning to Home.
  - Search input with clear button and real-time substring filtering across title and description.
  - Result list with interactive checkboxes, edit actions, and delete actions.
  - Empty search state illustration/message when no results match.
- `Frontend/src/components/home/HomeScreen.tsx`:
  - Integrate `TaskList` into the "Tasks Today" section with active selected date filtering.
  - Wire "View All" toggle to show all tasks for the week vs. selected date.
  - Wire FAB click to open Add Task modal.
  - Wire task item edit click to open Edit Task modal.
  - Wire task item delete click to trigger deletion.
- `Frontend/src/App.tsx`:
  - Support screen routing across `onboarding`, `home`, and `search`.
  - Mount `TaskModal` for creating or editing tasks.

## Verification Steps
1. Run `npm run lint` and verify zero errors.
2. Run `npm run build` and ensure successful bundle output.
3. Test end-to-end task workflows: creating, editing, status toggling, swipe-deleting, searching, and weekly summary metric updates.
