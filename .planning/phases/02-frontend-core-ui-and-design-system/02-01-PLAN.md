# Phase 2: Plan 1 - Tailwind Setup, Theme Tokens, Mobile Frame & Onboarding Screen (Tracer)

## Objective
Establish the Tailwind CSS styling pipeline in Vite, configure custom design tokens matching the Figma color palette, implement the responsive mobile container frame, and build the pixel-accurate Onboarding Screen with persistent navigation state.

## Proposed File Changes
- `Frontend/package.json`: Add `@tailwindcss/vite`, `tailwindcss`, and `lucide-react`.
- `Frontend/vite.config.ts`: Integrate Tailwind CSS Vite plugin.
- `Frontend/src/index.css`: Define Tailwind imports, `@theme` color variables, and global typography.
- `Frontend/src/assets/onboarding-bg.png`: Copy Figma hero background graphic from root into frontend assets.
- `Frontend/src/components/layout/MobileContainer.tsx`: Responsive chassis component (max-w-[420px] simulated mobile frame on desktop, 100% full-screen on mobile).
- `Frontend/src/components/onboarding/OnboardingScreen.tsx`: Frame 1 implementation (hero graphic, "Manage What To Do" title, subtitle, full-width blue "Get Started" CTA, and `localStorage` flag handler).
- `Frontend/src/App.tsx`: Screen routing logic toggling between `onboarding` and `home` based on `localStorage`.

## Verification Steps
1. Run `npm install` in `Frontend/` and ensure dependencies install cleanly.
2. Build frontend using `npm run build` without TypeScript or bundle errors.
3. Verify Onboarding Screen renders graphic and button, and switches to Home screen on click.
