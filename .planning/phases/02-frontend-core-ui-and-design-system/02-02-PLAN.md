# Phase 2: Plan 2 - Home Screen Structural Components (Header, Date Strip, Summary Cards, Progress Bar, FAB)

## Objective
Implement the complete structural anatomy of the Home Screen matching Figma Frame 2, including the top header bar with search input and action icons, the dynamic 7-day date strip selector, the weekly summary cards ("Task Complete" and "Task Pending"), the weekly progress bar, the "Tasks Today" section header, and the centered floating action button.

## Proposed File Changes
- `Frontend/src/types/task.ts`: Frontend type definitions matching backend (`Task`, `TaskPriority`, `TaskStatus`, `WeeklyStats`, `DayItem`).
- `Frontend/src/utils/date.ts`: Date utilities for generating the 7-day week array, formatting dates, and comparing days.
- `Frontend/src/components/home/Header.tsx`: Top bar containing settings gear icon, search input bar with search icon, and notification bell icon.
- `Frontend/src/components/home/DateStrip.tsx`: 7-day horizontal day selector displaying weekday abbreviation and day number with active blue pill highlight and white indicator dot.
- `Frontend/src/components/home/SummaryCards.tsx`: Dual card grid displaying "Task Complete" (light blue) and "Task Pending" (light salmon) with respective counts, icons, and "This Week" subtitles.
- `Frontend/src/components/home/ProgressBar.tsx`: "Weekly Progress" section with rounded horizontal progress bar and completion percentage.
- `Frontend/src/components/ui/FloatingActionButton.tsx`: Centered floating action button (`+`) positioned at the bottom of the viewport.
- `Frontend/src/components/home/HomeScreen.tsx`: Assemble Header, DateStrip, SummaryCards, ProgressBar, "Tasks Today" section with "View All" link, and FAB into a cohesive layout with mock/preview data.

## Verification Steps
1. Run `npm run build` in `Frontend/` and ensure compilation passes with zero type errors.
2. Verify all UI components render correctly inside `MobileContainer`.
3. Verify clicking days on the `DateStrip` updates the active selected date indicator.
4. Verify summary cards and progress bar dynamically render provided metrics.
