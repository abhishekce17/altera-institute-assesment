# Phase 4: Plan 2 - Dev Proxy, Netlify Configuration & Environment Files

## Objective
Configure development proxying in Vite, set up Netlify deployment files (`netlify.toml` and `_redirects`), and establish environment variable templates for production deployment.

## Proposed File Changes
- `Frontend/vite.config.ts`:
  - Add `server.proxy` forwarding `/api` to `http://localhost:5001` with `changeOrigin: true`.
- `Frontend/public/_redirects`:
  - Standard Netlify SPA redirect rule: `/*  /index.html  200`.
- `Frontend/netlify.toml`:
  - Netlify build configuration:
    - Base: `Frontend`
    - Publish: `dist`
    - Command: `npm run build`
    - Redirects: `from = "/*"`, `to = "/index.html"`, `status = 200`.
- `Frontend/.env.example` & `Frontend/.env`:
  - `VITE_API_BASE_URL`: Documented and configured.

## Verification Steps
1. Run `npm run build` in `Frontend/` and ensure compilation passes.
2. Verify `dist/_redirects` is copied to build output for Netlify.
