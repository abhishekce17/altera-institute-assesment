# Phase 1: Plan 1 - Core Express Server, MongoDB Model & CRUD Endpoints (Tracer)

## Objective
Establish the foundational Express.js application with TypeScript, Mongoose connection, the `Task` model, and core CRUD routes (`GET /api/tasks`, `GET /api/tasks/:id`, `POST /api/tasks`, `PUT /api/tasks/:id`, `PATCH /api/tasks/:id/status`, `DELETE /api/tasks/:id`).

## Proposed File Changes
- `Backend/package.json`: Configure dependencies (`express`, `mongoose`, `dotenv`, `cors`, `morgan`), scripts (`dev`, `build`, `start`), and type definitions.
- `Backend/tsconfig.json`: TypeScript configuration for Node.js 18+ (ES2022 / NodeNext or CommonJS).
- `Backend/.env.example` & `Backend/.env`: Environment variables (`PORT=5001`, `MONGODB_URI=mongodb://localhost:27017/todo-app`, `CLIENT_URL=http://localhost:5173`).
- `Backend/src/config/db.ts`: Robust MongoDB connection handler with retry logic and graceful shutdown.
- `Backend/src/models/Task.ts`: Mongoose Task schema matching `ITask` interface with `weekStart` computation hook and indexes.
- `Backend/src/utils/dateUtils.ts`: Pure functions for ISO week calculation (Monday to Sunday) and `weekStart` calculation.
- `Backend/src/controllers/taskController.ts`: Controller functions for create, get all, get by ID, update, patch status, and delete.
- `Backend/src/routes/taskRoutes.ts`: Express router connecting routes to controllers.
- `Backend/src/app.ts`: Express app configuration with CORS, JSON body parser, morgan logging, task routes, and 404/error middleware.
- `Backend/src/server.ts`: Server entrypoint that connects to MongoDB and calls `app.listen()`.

## Verification Steps
1. Install dependencies in `Backend/` (`npm install`).
2. Build TypeScript files with `npm run build` (or verify type-check with `npx tsc --noEmit`).
3. Verify `app.ts` exports Express application cleanly.
4. Verify all route handlers exist and adhere to REST conventions.
